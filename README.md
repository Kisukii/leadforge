# 🚀 LeadForge CRM

LeadForge is a full-stack CRM (Customer Relationship Management) web application built to manage leads, track pipeline stages, and analyze business performance.

---

## 🔗 Live Demo

Frontend: https://your-vercel-link  
Backend: https://leadforge-x8t8.onrender.com

---

## 📌 Features

- 🔐 User Login (Basic Authentication)
- 📊 Dashboard with key metrics
- 📁 Leads Management
- 🔄 Pipeline Tracking (New → Contacted → Proposal → Closed)
- 📈 Analytics Overview
- 🌐 Full-stack integration (Frontend + Backend)

---

## 🛠️ Tech Stack

### Frontend
- React (Vite)
- Tailwind CSS

### Backend
- Node.js
- Express.js
- CORS

### Deployment
- Frontend: Vercel
- Backend: Render
